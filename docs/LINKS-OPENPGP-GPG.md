## Como validar um link

1. Abra a URL no navegador (logado ou anônimo no GitHub).  
2. A página deve rolar até o **título** do módulo/COMANDO — não ficar no README do repo.  
3. Se falhar: confira se o PR de âncoras foi mergeado em `OpenPGP-GPG-do-Zero-ao-Expert` `main`.
